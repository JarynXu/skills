# iCenter CDP 连接与客户端能力

## 变更及来源

比较基线为 `main` 的 `3767146573e28451c42b8736a41eca450c9ea371`。实现与验证资源随本记录提交，变更范围由基线与本记录所在提交的差异确定。此前版本允许在 CDP 未开启、专用命令缺失或版本不兼容时转向桌面工具。本次要求客户端任务使用 CDP；操作系统进程管理承担建立 CDP 前的启动与重启。

`connect` 负责连接准备。已有端口复用；客户端未运行时从安装信息发现程序并启动；普通运行的实例需要明确的重启许可。多实例必须选择 PID。已开启端口无法就绪时保留原实例，不重启。重启保留程序路径和启动参数，限定所选进程树。

`targets --all` 与通用 `cdp` 请求提供未封装功能的页面入口。专用 Vue 适配器与 CDP 传输分别判断。单次通用请求默认预览；多步节点操作通过已有 `CdpClient` 复用一个连接。新增功能没有引入 npm 依赖。

用户补充运行环境不能假设 computer use，要求研究已有客户端操作。后续增加 `RendererSession`，承接有账户及可选会话约束的页面工作流；任务参考补入当前版本的 DOM、组件处理方法、状态字段和跨页面边界。连接、传输、专用消息操作、页面工作流分别维护各自契约。没有为每个菜单建立命令，也没有将通用 CDP 入口等同于功能已经适配。

文件下载由 `attachments.cjs` 调用当前客户端保存框之后的附件服务。适配器限定版本、账户、会话和消息，拒绝覆盖已有输出，检查客户端确认及实际可读文件。它借用页面会话，不承担连接生命周期；通用页面工具不内嵌文件业务。

## 客户端能力检查

研究读取本机安装包中的界面实现与当前渲染状态，未复制厂商代码进入技能。以下区分真实动作与入口、契约检查；没有进行整套功能的外部写入验证。本次全部客户端操作使用 CDP，未使用 computer use。

| 功能 | 实际证据与限制 |
|---|---|
| 通知设置 | CDP Input 打开设置及通知页，读取自定义复选框选中类，得到声音关闭、闪烁开启。未点击开关。关闭面板和菜单，核对账户、当时会话和全部编辑器 HTML 保持相同。 |
| 联系人与本人邮箱映射 | 从通讯录导航，通过实际主搜索 input 查询本人；客户端搜索结束，返回一个联系人。结果的 unionID 与登录关联 ID 一致，工号与 SIP 的数字部分一致。邮箱摘要为占位符，详情字段去除空白后为空；未取得有效邮箱。没有按姓名或 SIP 构造邮箱，没有导出整个通讯录。 |
| 文件发送 | 从已加载会话确认本人会话 ID，调用当前编辑组件的 `uploadFile({target:{files,...}})`。新增文件消息的本人发送者、文件名、客户端消息确认及文件传输确认成立。没有打开原生选择框，没有替换全局对话框方法。 |
| 文件大小与缓存 | 首次将 `getFileSize()` 当原文件长度比较，结果不相等。读取当前方法及本地文件确认：源文件 41 字节、消息元数据 133、缓存 225，三者不是同一表示。源路径文件哈希仍与生成物相同；这不是接收端重新下载后的哈希验证。参考已区分元数据、缓存和实际原文件。 |
| 指定路径下载 | 研究保存框之后的现有附件服务，通过 CDP 下载本人测试文件。随后用正式 `downloadFile` 入口复验：预览未创建输出，执行返回同一消息和会话、原件路径及传输成功，新文件 41 字节，SHA-256 与源文件一致。账户、会话、全部编辑器 HTML 及模块队列长度保持相同。没有打开保存框或替换全局对话框方法。 |

| 群资料 | 选择一个已读且缓存显示有效的群，只读打开资料侧栏，取得群操作组件的成员、公告、权限、二维码、同步、导出、机器人和应用契约，关闭并回到本人会话。没有修改群或发消息。 |

## 当前限制与状态

验证结束时，真实客户端已登录并启用回环 CDP，保持运行。真实多账户、会议、短信、直播、企业应用写入和权限差异未做端到端验证。普通文件收发取得无原生对话框路径；媒体、合并转发子附件与桌面区域截图未完成同类实测。外部浏览器需要独立 CDP 和认证。技能保留这些限制，不回退桌面自动化，不宣称已实现或验证客户端全部功能。
