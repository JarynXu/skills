# iCenter 重构与验证

## 产物与边界

新增 `skills/icenter/`，主入口按任务连接九份参考。仓库索引从 18 项更新到 19 项。原下载包保留在用户提供的本地目录，未覆盖原版。

技能覆盖账户与本人身份、联系人和群组、消息检索与整理、文本和富内容发送、文件与收藏、消息监控、会议通话、短信、工作台和客户端设置。主入口定义身份、授权、状态和完成依据；参考承接对应操作。企业群名、排障规则、固定测试收件人和多智能体调度不进入运行时内容。

## 实现选择

纯界面方案依赖焦点、虚拟列表和可访问性；把所有能力接入私有 SDK 需要承担未公开的参数、会话和回调契约。本次采用本机 CDP 查询与有限写入工具，保留其他能力的可观察界面路径。选择依据是已有字段证据、可验证的状态与维护范围。

六个脚本各自持有对应职责：连接启动、CDP 传输、身份与游标契约、厂商版本适配、操作生命周期、命令输入输出。适配器针对 iCenter 12.1.0；Windows 文件版本为 12.1.0.662。版本或结构不匹配时拒绝脚本路径，参考说明界面处理方式。

移除了原版不被实际使用的 `ws` 依赖、技能目录外的运行时路径、重复脚本体系、隐式强制重启和固定多智能体编排。新版使用 Node.js 原生 WebSocket，不需要 `npm install`。主窗口由运行时角色识别；同一客户端的三个 `app://./index.html` 页面不能按排列顺序选择。

查询和发送使用账户与会话 ID。已有文本、富内容或引用草稿阻止发送。新增消息 ID、发送人、正文与客户端传输状态共同构成发送确认。超时和断连保留未知状态，脚本不重发。监控使用有界游标、总时限、空闲时限和检查点；窗口失去锚点时报告缺口。

## 原版缺陷复现

[只读复现程序](evals/source-probe.cjs)对原版模块使用隔离替身，[原始结果](evals/source-results.json)记录 12 项缺陷及来源哈希。程序未连接真实客户端，没有消息副作用，原文件哈希保持不变。

复现涵盖：部分名称误定位、同名对象合并、读取错误转空列表、编辑器清空被当成发送成功、会话切换后错误标记来源、按正文前缀去重、空闲期限不随消息更新、PowerShell 日志破坏 JSON、CDP 协议错误被当成成功、连接错误与断开遗留请求、群设置标签被当成开启状态。

复查命令需要保留的原下载包：

```text
node docs/icenter/evals/source-probe.cjs "<原包>/icenter/scripts"
```

该程序证明上述固定输入中的旧版行为，不证明所有真实客户端都出现同样现象。新版把姓名限于搜索候选，把未知群设置交回实际状态读取，没有继续维护原版的猜测路径。

## 实际执行证据

运行环境为 Windows、Node.js 26.8.1、Python 3.14.6、iCenter 12.1.0.662。用户授权收发测试对象为本人。客户端资料与登录状态提供了同一账户的对应证据。没有给其他人或群发送测试消息。

| 验证项 | 结果与限制 |
|---|---|
| 连接探测与启动 | 探测返回主进程及端口；已有进程时拒绝另行启动。用户退出后使用动态回环端口启动成功，状态查询识别主窗口与登录主体。 |
| 对象查找 | 查询得到本人会话的精确 ID；选择预览和应用返回相同对象。错误账户、未知会话命令以非零状态拒绝。 |
| 文本发送与读取 | 自聊发送一条测试文本。客户端确认消息 ID；再次读取的正文与 UTF-8 文件相同，保留中文、换行及 `<>&"`。截图核对可见消息气泡。 |
| 新消息监控 | 已启动的监控捕获上述消息 ID，空闲时限到达后结束并写入检查点；恢复命令通过同一作用域检查并结束。不是后台常驻服务测试。 |
| 草稿保护 | 在空编辑器写入本次自建测试草稿；发送命令返回 `DRAFT_PRESENT`。原测试草稿内容保留，随后按精确文本及作用域核对移除。未发送该草稿。 |
| 文件发送 | 通过文件分享入口向自聊发送一个 281 字节文本文件。新增文件消息具有 ID，客户端消息与文件传输谓词均成功；界面显示“发送成功”。本机已有原文件，不算一次服务端下载验证。 |
| 自动化测试 | `node --test skills/icenter/tests/*.test.cjs` 与技能 `tests/test.sh` 通过 41 项。包含真实 CLI 子进程和本机 HTTP 发现测试，其余为协议、DOM 契约与行为替身；不能合称 41 项真实客户端测试。 |
| 技能格式与发现 | `python scripts/validate_repository.py` 通过；`npx skills add . --list` 返回 19 个技能并包含 iCenter。 |

测试消息留在本人会话，便于复核。本地日志和真实标识留在忽略目录 `.tmp/icenter-audit-20261011/`，没有打包到技能中。工具输出与本次会话中的截图是现场证据；公开文件记录验证范围，不分发企业聊天截图或厂商源码。

测试结束后通过客户端退出确认关闭调试进程，按普通方式重启。进程探测确认新实例的 CDP 端口为 0，测试监控进程已结束。最终脚本哈希及命令结果见[验证记录](evals/verification.json)，41 项检查的输出见[测试日志](evals/icenter-tests.txt)。

## 模型行为证据

[独立对照记录](evals/behavior-results.md)保留同一模型、同一题目下原版与候选的首次操作决策。候选加载了与任务对应的参考，保留草稿、未知发送结果、监控缺口及身份歧义。原版也表现出部分相同的克制行为，不能把这些行为都归因于重构。

完整模型验收没有取得全项证据：候选没有展开发送后的消息 ID 与完整正文比较；确定性发送工具执行这些检查。没有进行跨模型效果统计，也没有把模型文字判断视为真实工具执行。

## 全仓检查

原 `scripts/test_all.sh` 在 Windows 失败，停在既有 backend-engineer 测试。默认 Python 编码影响其文本匹配；启用 `PYTHONUTF8=1` 后，失败定位到 `offline_library.py search ownership --source rust-book` 的路径断言。实际输出包含 Windows 反斜杠，断言要求 `processed:rust-book/`。此前 Coremail 验证记录中已有此差异，相关文件本次未改动。

其余八个测试入口在 Windows UTF-8 环境逐项执行，退出码均为 0：Coremail、iCenter、DevOps、Draw.io、Frontend、Project Manager、QA、SVG。原全仓 runner 仍然失败，不能将分项结果写成全仓通过。没有关闭检查或为通过检查修改其他技能。

## 未覆盖的验证

真实多账户切换、企业别名映射、他人收件回执、群成员变更、批量历史完整性、服务端文件下载、会议邀请与取消、音视频和共享、短信发送及企业应用写入没有实测。技能提供这些任务的界面操作和验收契约，相关权限与结果需要在实际任务中核验。

当前端到端证据支持本机版本的连接、查询、文本和文件发送、草稿保护与有界监控。发布其他客户端版本前需要重新核对版本适配器。全仓跨平台测试问题属于仓库发布前的已知检查缺口。
