# iCenter 客户端升级适配

## 范围与版本

基线为 `b2fc836061f213daacae9b5941bfaa6f227d81bc`。本轮修改对应用户安装的 iCenter 12.6.8，Windows 文件版本为 12.6.8.13，Electron 为 22.3.27。运行环境为 Windows、Node.js 26.8.1。用户完成登录后，验证使用该客户端与本人会话。

运行包的参考版本仍由 [client-version.json](../../skills/icenter/scripts/client-version.json) 维护。版本差异不触发拒绝、提醒或路径切换；接口指纹、参数结构、账户和结果检查保留。本轮没有建立多版本目录、兼容矩阵或安装依赖。

## 适配内容与契约核对

升级前目录的 451 个 SDK 操作中，73 个方法指纹匹配，378 个发生变化。逐服务检查当前方法、导入映射、参数位置及原生调用；刷新模型、枚举、配置写入器和图片解码器指纹。新目录登记 461 个操作、277 个模型、190 个枚举。

- 原有 451 个操作保持登记，新增语音自动转文字开关、本人自定义状态、成员调岗通知全局开关、会议热词与转写资源操作，共 10 个入口。初始化、认证及内部事件处理函数未作为业务操作开放。
- 出差与休假同步分别占一个参数；群资料查询增加原因参数；成员移除、视频、卡片及自定义分享的可选参数位置更新。参数说明跟随当前源码，不复用旧回调位置。
- 移除不再是模型类的两个导出，补入十个模型，含本人自定义状态模型；更新已变化的枚举，补入一个枚举。没有为旧导出创建别名。
- 日历和智能助手的原生入口 chunk 已变化，日历模块 ID 已变化。三个原生应用入口的指纹更新。认证材料继续留在客户端。

`sdk-check` 对 461 个操作返回 `contract-matched`。`describeType` 对 277 个模型通过。七个网页应用的 439 个已登记操作完成方法、模块或来源核对，无方法差异。这些检查没有执行对应写入。

云盘 OpenAPI 两次返回的 SHA-256 不同。保留响应后按 JSON 对象递归比较，差异仅为对象键序，348 个路径与 304 个模型的内容相同。其中一份字节摘要与原登记值一致，目录和模型无需修改。

## 真实客户端执行

| 对象 | 本轮执行与观察 |
|---|---|
| 文本与历史 | 向本人会话发送一条测试文字；按 ID 读取的正文一致；本机历史包含该消息。客户端报告发送成功。 |
| 消息通知 | 建立本次被动订阅，收到同一条自发消息并确认接收；结束时移除本次订阅。 |
| 普通文件 | 向本人发送 57 字节测试文本，经准备与发送两阶段确认消息及文件传输成功；指定新路径下载，内容与源文件一致。 |
| 图片 | 向本人发送合成色块 PNG。客户端返回原生图片消息及成功状态；`readImage` 从大图缓存导出 128 × 96 PNG，宿主图片工具读到红、绿、蓝三个色块。`releaseImage` 删除本次临时输出，后续预览仍见客户端大图缓存。 |
| 设置 | 16 个已登记设置读取均取得客户端值与文件值，两者一致；未写入设置。 |
| 新增读取 | 本人自定义状态列表、成员调岗通知全局开关、会议热词读取均收到成功证据。状态列表与热词列表为空，具有 fulfilled 回调；群开关和热词响应的 success 为 1。 |
| 新增写入 | 七个新增写入入口完成真实客户端契约核对和预览；未执行业务写入。 |

账户与编辑器内容哈希保持一致。文本、文件和订阅测试结束时，聊天仍未选中；全轮结束时选中了本人聊天。切换来源没有记录，本轮不据此声称图片发送或整个验证过程保留了聊天选择，也未强行恢复选择。没有遗留 SDK 占用、本次订阅、临时 frame 或本次隐藏窗口。测试文字、文件和图片只发给本人，没有更改群成员、会议、同步偏好或清理客户端缓存。
