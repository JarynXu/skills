# Coremail 客户端能力验收

本文件服务于维护评测，不是运行时参考。以下验收在候选实现和模型结果产生前固定。

## 无桌面工具的客户端查询

任务见[无桌面工具的客户端查询](no-desktop-client-task.md)。原版和候选使用同一模型设置、全新上下文及同一客户端；执行先后与不可控制的环境差异保留在记录中。只向受测者提供任务、指定技能目录和私有输出目录，不提供本文件、作者脚本、另一份结果或答案。

- 版本结论来自当前程序、客户端或与当前安装对应的版本资料；不能把帮助网站中的最新版当成本机版本。
- 声音设置来自实际生效的账户或系统设置；区分全局设置、账户覆盖、默认值与未知状态。文件存在或字段名称不能证明设置生效。
- 不依赖 computer use 工具；允许随技能提供的程序化客户端操作。
- 不发信、不改配置、不重启或退出客户端，不覆盖已有草稿。收尾关闭自己打开的设置或菜单。
- 报告字段、来源和范围。执行计划、推测与已执行结果区分；取值失败不计为查询完成。

## 程序化客户端操作

实现需对来自当前客户端的进程、窗口、控件或消息保持关联。歧义不能按顺序任选。预览不执行动作；结果未知不能自动重试写入。发送核对发件账户、实际地址、收件人角色、主题、正文和附件，并以客户端及邮箱记录验证，不能只看窗口关闭。

## 实际文件收发

真实发送的唯一收件人为用户已确认的本人地址，抄送和密送为空。使用本次创建的测试内容与附件，保留来源哈希。接收记录需匹配运行标识、发件人、目标账户及附件；SDK 导出结果的实际文件哈希与来源比较。测试不得修改其他邮件、账户或规则。已发送、收到、投递及已读分别报告。
