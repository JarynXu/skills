# 客户端能力路由

SDK 负责其声明的结构化操作；CEF 原生桥与 Windows 适配器补足编辑器、发送、原邮件动作、原生表单和客户端设置。具体版本、账户协议、服务端策略和权限会改变可用能力。功能范围由客户端决定，不止于 SDK 的十五个函数。

## 以当前界面建立操作依据

读取[程序接口](client-interfaces.md)或[原生适配器](native-interface.md)，用随包脚本观察页面、窗口、标签、列表项和控件状态。核心执行不要求 computer-use、截图查看器或鼠标控制插件。CDP 不能直接操作主体 wxWidgets 控件，原生适配器也不能假装页面事件已执行。

在目标对象处打开相关菜单或页面，读取可用操作与作用范围。SDK 中没有函数是检查其他客户端接口的信号；没有入口时检查版本、权限、账户类型和客户端帮助，保留“未确认”或实际阻塞。不要宣称整个客户端不支持该任务。编辑器、阅读页、日历的事件和桥参数从当前安装的 `app/template` 检查；原生表单按名称、对象关系和实际状态操作。

## 按能力选择路径

| 能力 | 程序路径与完成依据 |
|---|---|
| 收信、同步、离线与账户状态 | SDK 读账户和文件夹；原生收信入口处理同步。区分本地已缓存、同步进行中和服务端状态；不把本地空列表当服务器无邮件 |
| 普通与高级检索、阅读、线程、附件导出 | [邮件与附件](mail-and-attachments.md)。索引错误时遍历明确范围；客户端搜索框由原生 Edit 操作，结果仍要核对范围与目标 |
| 新建、草稿、回复、回复全部、转发、发送 | [写信与发送](compose-and-send.md)。SDK 预填，CEF 编辑及消息桥，原生提示框，SDK 草稿和发件记录各承担对应证据 |
| 格式、签名、链接、图片、附件、正文模式 | 当前编辑器 app 和原生写信选项。检查资源实际加载、正文状态、签名边界及附件文件；HTML 显示不等于附件已附加 |
| 定时发送、单显、回执、重要性、撤回、投递状态 | 原生写信高级选项及原邮件菜单；阅读页有延迟发送取消等桥事件。核对账户支持、实际发送安排、队列及撤回反馈；不保证外部收件服务器支持 |
| 文件夹、移动、标签、已读、旗标、待办、置顶、备注、垃圾邮件 | [邮件整理](organize-mail.md)。已声明 SDK 优先；其他状态使用当前阅读页桥或原生菜单，查实际 Flags 与列表状态 |
| 个人联系人、分组、组织部门、通讯组、最近联系人、导入导出 | [通讯录与日程](contacts-and-calendar.md)。SDK 查询，原生 MainAddress 导航及维护表单；区别个人可修改数据与组织只读数据 |
| 日程、循环、提醒、邀请响应、空闲忙碌、会议室 | 同一参考中的日程契约。SDK 查询，CEF 日历及原生表单维护；日期导航、保存、邀请与响应分别验证 |
| 共享邮箱、代表或代理发送、本人别名与账户设置 | [连接与账户](connection-and-accounts.md)。SDK 账户关系与原生账号管理交叉核对；读取权限不代表修改或发送权限 |
| 来信分类、自动转发、规则顺序与历史邮件处理 | 原生邮件规则设置；核对条件、动作、顺序、作用账户和历史执行范围。保存规则与执行规则是两个动作 |
| 系统提醒、网络、回复习惯、热键、AI、日志与版本 | 原生系统设置、当前用户配置和 CEF 运行版本；区分系统、账户、服务端及安装默认值。配置文件只证明持久值，不证明生效状态 |
| 存档、恢复、导入导出、账号目录迁移 | 原生存档与数据维护流程；核对模式、源端处置、目标一致性和恢复材料。见下节 |
| S/MIME、密码或权限保护、二次验证、公共邮箱及扩展模块 | 原生安全选项、授权模块和服务端配置。需要的证书、许可、验证及管理员权限须真实具备；不绕过验证或解密边界 |

这张表覆盖客户端任务族，不承诺每个版本具备每项功能，也不宣称每条写入路径已经执行过。源码路由、官方说明、脚本可运行与具体业务动作的真实验证分别记录。当前客户端有新入口时沿用同一接口发现与结果核对方法，不向运行时加入开发任务的用户地址、样例邮件或窗口句柄。

## 操作与检查

1. 识别当前账户、文件夹、邮件、联系人、日程或设置页。选择项的数量和对象必须与任务吻合。
2. 根据可观察的状态执行一个连贯动作。界面变化后取得新证据，避免在过期坐标上连续操作。
3. 读取确认对话框和错误消息。确认框不是默认点击目标；检查其影响是否仍在用户授权内。
4. 从保存状态、目标列表、SDK 查询或文件检查结果核对变化。排队、进行中、失败和完成分别报告。

写信编辑器检查参见[写信与发送](compose-and-send.md)；对象整理参见[邮件整理](organize-mail.md)。授权由技能入口统一定义。

## 设置与数据生命周期

设置变更需要知道作用账户、原值、候选值及生效方式。跨账户、对外发送、数据删除、客户端重启或服务端同步的影响须落在用户请求范围内。保留可恢复的原状态；不可确认的设置不靠试错写入定位。

存档具有经典、打包、批量等模式，可能涉及本地留存和服务器删信。确认具体模式、源邮件范围、目标位置、服务器处置与恢复路径。存档完成后检查目标内容和源端状态；普通文件夹移动不能证明存档或备份完成。

账户目录迁移和恢复要遵循当前客户端支持的流程，核对源与目标并保留恢复材料。不得把复制正在写入的数据目录称为一致性备份。

客户端提供的人机验证、登录确认、管理员审批或权限门槛属于外部边界。需要用户或管理员处理时说明具体入口和缺口，不绕过控制。
