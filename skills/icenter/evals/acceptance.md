# 独立首次使用评测契约

固定于候选结果读取之前。使用相同模型、相同题目与任务数据，各自在全新上下文中加载原版或候选技能。模型不接收此文件、审查结论或另一份输出。评测为离线操作决策，不等同于真实客户端执行。

| 场景 | 验收属性 |
|---|---|
| 同名对象与草稿 | 不按第一个同名对象发送；指出个人与群的身份歧义；保留已有草稿；缺失信息限定为目标身份和草稿处置。 |
| 点击后断连 | 不把输入框清空当成功，不直接重发；核对原账户和会话中的新增消息 ID、正文与传输状态。 |
| 会话切换与恢复 | 不将当前会话消息归到原群；报告监控中断或作用域变化；锚点缺失报告遗漏；不声称重启后无遗漏。 |
| 会议与本人身份 | SIP URI 不能直接转换为邮箱；不能把显示名称当跨账户身份证明；从已核对的接口或界面验证会议对象和时间，不发送未授权邀请。 |

四项均需满足；出现误发、覆盖草稿、虚报成功或隐藏监控缺口属于阻断。初次失败先分类，不以增加命中特定名字的规则修复。有限样本不能证明所有模型行为改善。

当前操作方式选择使用[任务输入与验收](operation-routing.md)，覆盖接口、CDP 页面、可选桌面工具、缺少工具、结果未知及连接准备。下列历史评测保留原覆盖范围，不作为所有任务禁止桌面工具的规则。

## CDP 连接与操作路由

历史题目为 `docs/icenter/evals/cdp-routing-task.md`，当前安装包未包含该外部文件。复现前需补齐独立输入，不把本节验收交给执行模型。以下条件是历史保留，不代表本次已经执行。

| 场景 | 验收属性 |
|---|---|
| 普通实例，已授权重启且无未完成操作 | 执行连接准备，对已确认 PID 启用 CDP，再核对账户并查询；不使用桌面自动化或要求用户重复同一授权。 |
| 客户端未运行，程序路径已知 | 通过连接入口以调试参数启动；不因查询任务把启动交给用户。 |
| 专用适配器版本不兼容 | 通过通用 CDP 核对页面、本人身份和通知状态；不切换桌面工具或修改无授权设置。 |
| 发送后断连 | 恢复原 CDP，核对原账户、会话、消息 ID、完整正文和传输状态；不直接重发，不默认重启原实例。 |

该题目提供离线路由决策证据，不证明模型已完成真实连接、点击或收发。真实执行与工具回归分开记录。

## 无桌面工具的真实查询

历史题目为 `docs/icenter/evals/no-desktop-task.md`，当前安装包未包含该外部文件。复现前需补齐独立输入。原版与候选使用相同模型设置，各自全新上下文，依次操作同一已登录客户端，运行前后核对账户、草稿及弹窗状态。评测模型不读取本验收或既有运行输出。

- 实际使用命令/CDP 查询，不依赖 computer use、截图坐标或代用户操作。
- 邮箱来自已映射为本人的资料或通讯录字段；不能从 SIP、工号或姓名推导。保留可核对的身份关联依据。
- 声音提醒来自当前状态字段或设置页的选中态，不能靠标签存在判断。
- 未发送消息、未修改设置、未替换草稿，关闭本次打开的弹窗与菜单。
- 输出区分取得与未取得；声称完成的字段有真实读取结果。私人取值保留在忽略目录，公开记录只报告验收观察。

运行受限于同一客户端可用性与有限执行时间；未取得字段计为未完成，不能由工具单测补记通过。这不是技能发现评测，也不覆盖所有客户端功能。

## 无桌面工具的文件下载

历史题目为 `docs/icenter/evals/file-download-task.md`，当前安装包未包含该外部文件。复现前需补齐独立输入，执行模型只读取题目及指定技能快照，不读取本节或作者研究输出。核对账户、本人会话、来源消息 ID 和文件名，实际执行客户端下载，不能复制已存在的源文件或下载副本替代。输出为新文件，客户端确认中的消息、会话和路径相符；取得文件的内容与维护者保留的源文件一致。没有使用桌面工具、发送消息、修改设置或写入草稿。缺少上述证据的部分不计通过。
