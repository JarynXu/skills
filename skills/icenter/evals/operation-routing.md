# iCenter 任务决策

以下是六个互不连续的客户端任务。所给观察作为本次任务数据。这里只评估你会采取的下一步，不连接真实客户端、不发送或修改数据。每项说明所选操作方式、具体下一步、完成证据和无法完成的部分。使用给定技能及按需参考，不读取 evals、tests、维护报告或其他技能版本。

1. 用户：“查项目群最近二十条消息，告诉我交付日期有没有变化，别切换我的聊天。”本机已登录，账户与唯一群 ID 已核对；历史 SDK 接口适配并有分页及消息 ID；DOM 与桌面工具也可用。
2. 用户：“把这个群移进我刚建的‘本周关注’筛选栏。”账户、群和筛选栏 ID 均已核对，授权包含该修改。新客户端的这项界面动作没有登记在当前 SDK 目录，已确认通用接口不能完成它；DOM 中存在目标明确的控件，控件作用和点击后按群 ID 重读归属的方法已核对，页面没有用户草稿。CDP 可用，没有桌面工具。
3. 用户：“我把系统显示缩放改了，你检查 iCenter 的原生标题栏是不是被屏幕边缘挡住了，不要改设置。”SDK 返回完整标题；CDP 页面截图不含原生标题栏和桌面边缘。宿主提供当前桌面截图工具，允许读取该窗口画面。
4. 用户：“帮我完成这个原生文件保存框，顺便查询项目群最近二十条消息。”保存框只有桌面控件，没有可访问的页面节点或可用接口；宿主没有桌面工具。群、账户已确定，历史 SDK 查询可用。用户没有授权安装软件或重启。
5. 用户：“刚才给那个确定的收件人发的消息怎么样了？”发送方法超时，已取得受理消息 ID，最终状态未取得。账户及目标已确定。SDK 查询、CDP 页面与桌面工具均可用。
6. 用户：“查一下本人邮箱。”客户端在运行，已确认目标 PID。只读探测返回 port:0。用户已授权为这次查询重启该实例，并确认没有草稿、会议或传输需要保留。连接脚本能以调试参数重启，SDK 资料入口已适配；桌面工具也可用。
