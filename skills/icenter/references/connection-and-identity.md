# 连接与身份

## 运行环境和连接

脚本采用 Node.js 内置模块。原生 WebSocket 在 Node.js 22.4 起为稳定接口，见 [Node.js 文档](https://nodejs.org/api/globals.html#class-websocket)。安装 `ws` 不会替脚本补上这个全局接口。缺少运行环境时报告所缺能力和支持要求，不能把依赖安装写入用户当前项目。

从 `connections` 取得主进程 PID、程序路径、版本和命令行中的 CDP 端口。多个实例各自保留，不选第一个。`targets --port` 列出该端口的 iCenter 主页面；多个主页面使用 `--target-id` 指定。主页面存在只证明调试入口存在，`status` 才检查适配器和登录状态。

未开启 CDP 时，查询保持只读。任务需要 CDP 且允许重启时，检查草稿、文件传输和会议状态，从客户端的退出菜单关闭程序；再次探测确认退出。启动工具拒绝关闭已有进程：

```text
powershell -NoProfile -File "<技能目录>/scripts/connection.ps1" -Action start -ExecutablePath "<发现的iCenter.exe路径>"
powershell -NoProfile -File "<技能目录>/scripts/connection.ps1" -Action start -ExecutablePath "<发现的iCenter.exe路径>" -Apply
```

启动使用回环地址和动态端口。记录返回端口，不写入通用配置。登录或认证交给用户；登录等待结束后重新查询状态。`START_TIMEOUT` 表示已尝试启动、就绪状态未知，先查看现有进程，不能重复启动或强制杀进程。需要恢复普通启动方式时，通过客户端退出后按原方式打开；不要让任务遗留长期后台调试进程。

## 账户、本人和别名

实例、登录账户、用户本人、当前会话中的对方是四个对象。当前聊天标题和最近使用的联系人不能证明本人身份。

1. 从 `status` 取得登录账户的原始 ID 和名称。通过左上角本人头像资料核对工号或账户标识。不要移除前导零、截断域或根据姓名拼接 ID。
2. 当前账户归属用户需要会话授权或用户提供的上下文支持。共享电脑、代办账户、测试账户和多开客户端中，保留归属未知状态。
3. `unionId` 等客户端身份关联字段是有来源的关联标识。姓名、英文名、昵称和历史显示名属于显示信息，单独不能证明两个 ID 是同一人。企业、租户和账户边界仍需保留。
4. 别名或历史 ID 需要客户端资料、通讯录记录、明确的 ID 映射或用户确认。证据没有给出完整别名集合时，标注“已确认的标识”，不能称“所有别名”。
5. 本人识别用于筛选发送者、正式提及和回复对象。正式提及读取消息中的结构化身份；正文出现姓名只属于文本命中。处理转发和引用时保留原消息与当前发送者的区别。

同一实例切换账户会使旧会话 ID、消息游标及操作计划失效。每次执行传入 `--account`，读取时核对返回账户，跨账户重新查询目标。多个实例登录同一账户时，界面焦点和草稿仍各自独立。

## 版本与失败

CDP 是传输入口，客户端页面状态属于版本适配契约。当前适配器面向 iCenter 12.1.0；对象字段或页面结构不匹配时返回明确错误，不用空列表或猜测选择器作为降级。其他版本按界面路径完成任务，或在隔离测试中验证新适配器。

连接拒绝、登录未完成、多个页面、账户变化和版本不兼容各自报告。连接工具的成功退出不能证明消息已发送或后台监控仍在运行。
