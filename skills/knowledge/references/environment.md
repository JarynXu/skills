# 工具环境

这些是可选辅助脚本的运行条件，不是知识编写前必须完成的环境改造。

Python 3.10+；精确依赖在 `scripts/requirements.txt`。`kb.py --help` 不依赖这些包。优先使用项目已有解释器；需要安装时，在已授权的独立环境中执行，不修改业务或系统依赖：

```sh
python -m venv <临时环境>
<临时环境的Python> -m pip install -r <skill>/scripts/requirements.txt
```

Windows 的解释器通常在 Scripts，类 Unix 环境通常在 bin。依赖缺失会明确失败，不自动联网安装；应如实区分人工检查与未执行的脚本检查。

技能发现位置由宿主工具决定；不能发现时显式读取该技能的 SKILL.md，按需读取引用资料。项目 AGENTS 可以提供入口，但通用技能不假设任何固定目录、宿主、模型版本或项目多仓布局。

技能安装、副本同步和发布由项目或宿主已有机制处理。不要为一次知识维护添加新的插件配置、全局安装、根 Git 仓库或复制一套可分别编辑的技能源。
