# technical-clean

Default professional engineering style. Optimize for clarity, moderate density, restrained color, native editability, and documentation use.

- white canvas; dark neutral text;
- 12–14 px body labels, larger left-aligned titles;
- rounded service boxes; cylinders for data; diamonds for decisions;
- pale blue service, pale purple infrastructure, pale green data, pale yellow decision/config, pale red external/risk;
- light neutral containers with real parent-child containment;
- 1–1.5 px node borders; 2 px important relationships;
- orthogonal architecture/flow edges; straight UML sequence messages;
- dashed gray only for one documented secondary meaning;
- no decorative shadows/gradients by default;
- medium whitespace; labels concise and readable.

Use semantic tokens from `scripts/drawio_lib/styles.py` for repeatable execution.
