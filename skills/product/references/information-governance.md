# 信息治理

当任务需要管理证据状态、来源、稳定 ID、冲突或权威事实源时读取。治理的目标是保持主张的真实状态和可追踪关系，不是给每句话增加标签。

## 主张状态

只在状态会影响判断、确认权或后续使用时显式标记。

| 状态族 | 含义 | 常用标记 |
|---|---|---|
| 来源与观察 | 原始输入、直接观察或可核查材料 | `[SOURCE]`、`[OBSERVED]`、`[EVIDENCE]` |
| 已确认事实 | 已被适当证据或 authority 确认的客观事实与约束 | `[FACT]`、`[CONSTRAINT]` |
| 用户与业务需要 | 需要达成的结果，不等于具体方案 | `[NEED]` |
| 未确认判断 | 推断、待验证解释、暂用前提或候选方向 | `[INFERRED]`、`[HYPOTHESIS]`、`[ASSUMPTION]`、`[PROPOSAL]` |
| 正式产品定义 | 已确认决定及其产生的要求或规则 | `[DECISION]`、`[REQUIREMENT]`、`[RULE]` |
| 未闭合事项 | 未知、冲突、异常、风险或无法判断原意的现状 | `[OPEN]`、`[CONFLICT]`、`[ANOMALY]`、`[RISK]`、`[UNKNOWN-INTENT]` |

标签不是正文格式要求。对话或短产物可以用自然语言表达状态；正式记录、跨文档引用或高风险主张才需要结构化标记。

## 合法状态转换

状态只能依据新增证据或有权决策变化：

```text
来源或观察
→ 有证据的推断
→ 假设、待验证判断或候选方案
→ 有权主体确认的决定
→ 正式要求或业务规则
```

这不是要求每项内容经过全部步骤。它定义的是不得跳过的确认边界：

- 用户提出的想法不是自动成立的用户需要或正式需求；
- 当前系统行为只证明现状，不证明正确意图；
- Agent 选择的设计方向可以成为推荐方案，不能自行变成业务批准；
- 技术建议或偏好不能自动成为不可违反的约束；
- `Confidence: High` 表示对解释的信心，不等于获得正式确认。

记录状态变化时保留触发变化的证据或 decision authority。

## 证据记录

当结论将被正式持久化、影响重大产品决定或需要他人复核时，记录足够的证据上下文：

- 来源及可定位位置；
- 观察或原始主张；
- 适用范围、版本和时间；
- 解释及其与证据的距离；
- 可信程度和验证状态；
- 是否已经进入权威产品定义。

证据不足时降低主张状态或范围，不以篇幅弥补。对话中的暂时判断不需要为了形式创建证据文件。

## 来源登记

仅在已经获得写入授权，并且来源将被产品定义库持续引用、比较或审计时创建或更新 `source-register.md`。登记内容应足以回答：来源是什么、由谁或什么系统产生、何时有效、适用于哪里、可信程度如何、是否仍有效。

以下情况不单独创建来源登记：

- 只进行对话、解释或只读审查；
- 用户只要求一个不进入持续维护仓库的独立产物；
- 来源只在当前回复中临时使用，且不承担后续权威作用。

## 稳定 ID

仅当信息需要稳定引用时分配 ID。满足任一条件即可：

- 被多个文件、角色或下游产物引用；
- 需要跨版本追踪变化；
- 属于正式需求、规则、决定、风险、开放项或验收关系；
- 标题可能变化，但引用身份必须保持；
- 需要在审查、测试或交接中精确定位。

不要给临时对话、一次性解释、普通段落或没有引用关系的细节机械编号。

建议按语义使用稳定前缀，例如：

```text
SRC EVD GOAL METRIC USR NEED SCN OBJ PROCESS STATE
REQ RULE CONSTRAINT DEC ASSUMP OPEN CONFLICT RISK
OBS ANOMALY AUDIT NORM ARCH-IN UX-IN AC
```

ID 使用 `<TYPE>-<SCOPE>-<NUMBER>` 或现有仓库约定。标题、文件或措辞变化不应改变同一事项的 ID。

## 权威事实源

一个主张只能在一个权威位置完整定义。选择权威位置时依据其语义责任和维护主体，不依据最先出现的位置。

- 其他位置通过稳定 ID 或链接引用，不复制略有差异的全文；
- 新输入与权威定义冲突时，建立 `[CONFLICT]`，不要静默覆盖；
- 推断尚未获得确认时，保留在假设、候选或重建结论中，不写成正式规则；
- 变更权威事实时，更新受影响引用和追踪关系，但只触及真实依赖项。

## 治理停止条件

当每个重要主张都有真实状态、必要来源可定位、需要引用的事项有稳定身份、冲突与未知没有被隐藏，并且不存在竞争性权威定义时，治理已经足够。不要继续为了增加标签、记录或文件而扩展。
