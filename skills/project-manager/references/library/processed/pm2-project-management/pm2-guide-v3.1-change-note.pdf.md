Change Note for the update of the PM² Guide from v3.0.1 to v3.1
The publication of this new version of the PM² Guide v3.1 is a minor release that does not change the PM²
Methodology in any way. It serves the following purpose:
1) Reference contemporary areas of concern in project management, such as Sustainability, Data
Protection, IT Security, and UX. Added in the Appendix.
2) Implement corrections of minor mistakes and omissions from the v3.0.1 Guide.
3) Update the copyright statement to be aligned with the EC’s standard CC BY 4.0 license.
4) Implement updates to enhance the reading experience, but without changing any critical aspect of
the methodology guide.
In more detail:
1) Reference contemporary areas of concern:
New appendix sections present project management considerations which are pertinent to specific
domains. For instance, in the context of IT projects, considerations for Data Protection, IT Security, and
UX are critical. While sustainability considerations are more central to engineering or construction
projects, they remain relevant across diverse project domains. These considerations are introduced
through brief half page sections, as it is not the purpose of a generic methodology guide (such as the
PM² Guide) to overly expand on these.
a. Appendix D has been renamed from PM² Extensions to PM² Extensions & Considerations.
b. Four new sections have been added to Appendix D to introduce Sustainability, Data Protection,
Information Security, and UX.
c. A new section has been added: D.2 Considerations in PM²: Sustainability, Data Protection, IT Security,
UX to include the following 4 sub-sections:
• D.2.1 Sustainability Considerations in Project Management
• D.2.2 Data Protection Considerations in Project Management
• D.2.3 IT Security Considerations in Project Management
• D.2.4 Lean UX Considerations in Project Management
d. The change to the Table of Contents of the Guide was minimised to the following:
