# Repository instructions

Read [CONTRIBUTING.md](CONTRIBUTING.md) before changing this repository. It owns package layout, maintenance resources, version control, submission checks, and release boundaries.

Before creating, redesigning, auditing, or updating a skill, fully read [skill-creator](skills/skill-creator/SKILL.md) and follow its routes for the task. It owns skill design and validation methods. Installed initializers and repository templates supply scaffolding; they do not replace this authoring method.

Keep each requirement in its owner above. Use links from other documents instead of maintaining another definition. Apply repository checks to the properties they inspect; use the skill-creator method for evidence about changed skill behavior.
